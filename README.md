# Transmassa — Escala com Rotatividade

Apresentação React/Vite em 4 páginas:

1. Apresentação
2. O modelo
3. Demonstração prática e interativa
4. Agradecimento

## Rodar no Windows

```bat
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite (normalmente http://localhost:5173).

## Build

```bat
npm run build
npm run preview
```

Use as setas do teclado ← → ou o menu superior para navegar.

Na página 3, é possível arrastar um motorista até o serviço, clicar em **Empenhar** ou usar a seta para enviá-lo ao fim da fila com justificativa obrigatória.
